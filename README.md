# Portfolio - Consultant SAP

Portfolio professionnel présentant mes compétences et missions en tant que consultant SAP.

## Technologies utilisées

- HTML5
- CSS3
- JavaScript
- Formspree (formulaire de contact)

## Structure du site

- **Accueil** : Présentation et navigation principale
- **Projets** : Missions et réalisations SAP
- **Compétences** : Technologies et expertises
- **Contact** : Formulaire de contact

## Fonctionnalités

- Design dark mode
- Responsive (mobile, tablette, desktop)
- Formulaire de contact fonctionnel
- Navigation claire entre les pages

## Déploiement

Site hébergé sur GitHub Pages.
